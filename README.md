# 휴가봇 🌴

구글 시트를 데이터베이스로 쓰는 **Google Chat 휴가 관리 봇**입니다.
Google Apps Script로 동작하므로 별도 서버 없이 무료로 운영할 수 있습니다.

## 기능

| 명령 | 설명 |
|---|---|
| `/휴가사용` | 휴가 등록. **명령만 보내면 날짜·종류를 클릭으로 고르는 양식(대화상자)이 열린다.** 텍스트 등록도 지원: `7/28 10:30-15:30`, `7월28일 오전반차`, `8/3~8/5 일반휴가`, `내일 종일 보건휴가` |
| `/휴가취소` | 등록한 휴가 취소. 예) `/휴가취소 7/28` |
| `/휴가조회` | 내 잔여 휴가(종류별)와 예정 휴가 — **본인에게만 보임** |
| `/휴가현황` | 특정 날짜의 휴가자 목록. 예) `/휴가현황 내일` |
| `/근무현황` | 시간표 기반 근무 시간 막대그래프. `/근무현황`(오늘, 개인별), `/근무현황 이번주`(요일별 합계) |
| `/근무표` | **시간대(행)×사람(열) 근무표** — 휴가·점심 반영, 날짜마다 자동 생성. 예) `/근무표`, `/근무표 내일` |
| `/휴가전체현황` | 전체 구성원의 잔여 휴가 표 — **관리자 전용**, 본인에게만 보임 |
| `/휴가도움말` | 사용법 안내 |

### 기존 봇 대비 개선점

- **각자 등록**: 구글챗 계정 이메일로 명단에서 본인을 찾아 자동 매칭
- **휴가 종류 검증**: `휴가종류` 시트에 있는 종류만 등록 가능, 종류별 잔여 시간 자동 차감
- **공개/비공개 구분**: 등록·현황 메시지는 톡방 전체에 보이지만, **보건휴가처럼 `비공개`로 지정한 종류는 본인에게만 보이고** 현황·공지에는 종류명 없이 "휴가"로만 표시
- **입력 편의**: 기간 등록(`8/3~8/5`), 반차, 상대 날짜(`내일`, `다음주 월`), 주말·공휴일·개인 휴무일 자동 제외
- **중복 방지**: 같은 시간대에 이미 등록된 휴가가 있으면 거절
- **근무 시간 그래프**: `시간표` 시트(요일별 근무시간)를 기반으로 휴가를 반영한 실제 근무 시간을 막대그래프로 표시
- **매일 아침 자동 공지**: 오늘의 근무 현황 그래프 + 휴가자 목록을 지정한 시각에 톡방에 게시
- **관리자 잔여현황**: `잔여현황` 시트에 전체 구성원의 종류별 부여·사용·잔여가 자동 갱신됨 (스프레드시트 메뉴 [휴가봇 🌴 → 잔여현황 갱신] 또는 매일 아침 자동). 설정 시트의 `관리자`에 등록된 사람은 톡방에서 `/휴가전체현황`으로도 확인 가능
- **동시 입력 보호**: 여러 명이 동시에 등록해도 데이터가 꼬이지 않도록 잠금 처리

## 설치

### 1. 스프레드시트와 Apps Script 준비

1. 새 구글 스프레드시트를 만든다 (기존 휴가 관리 시트를 써도 됨).
2. 메뉴 **확장 프로그램 → Apps Script** 를 연다.
3. 이 저장소의 `appsscript.json`과 `src/*.js` 파일 내용을 그대로 붙여넣는다.
   - 파일이 여러 개이므로 [clasp](https://github.com/google/clasp) 사용을 권장:
     ```bash
     npm i -g @google/clasp
     clasp login
     cp .clasp.json.example .clasp.json   # scriptId를 본인 것으로 수정
     clasp push
     ```
   - `appsscript.json`이 보이지 않으면 편집기 설정에서 "appsscript.json 매니페스트 파일 표시"를 켠다.
4. 편집기에서 **`setupSheets` 함수를 한 번 실행**한다 → `설정`, `휴가종류`, `명단`, `시간표`, `휴가기록`, `공휴일` 시트가 자동 생성된다.
5. 생성된 시트를 실제 구성원에 맞게 수정한다 (아래 "시트 구성" 참고).

### 2. Google Chat 앱 등록

1. Apps Script 편집기 → **배포 → 새 배포 → 유형: 추가 기능(Add-on)** 이 아닌 **"Chat 앱"** 배포가 가능하도록, 먼저 프로젝트 설정에서 GCP 프로젝트를 연결한다.
2. [Google Cloud Console](https://console.cloud.google.com/)에서 해당 프로젝트에 **Google Chat API**를 사용 설정한다.
3. Chat API → **구성(Configuration)** 탭에서:
   - 앱 이름: `휴가봇`, 아바타/설명 입력
   - 기능: "1:1 메시지 수신", "스페이스 참여" 모두 체크
   - 연결 설정: **Apps Script 프로젝트** 선택, 배포 ID 입력
     (Apps Script에서 **배포 → 새 배포 → 유형: Chat 앱** 후 배포 ID 복사)
   - **슬래시 명령 등록** (이름 / 명령 ID):
     | 명령 | ID |
     |---|---|
     | /휴가사용 | 1 |
     | /휴가취소 | 2 |
     | /휴가조회 | 3 |
     | /휴가현황 | 4 |
     | /근무현황 | 5 |
     | /휴가도움말 | 6 |
     | /휴가전체현황 | 7 |
     | /근무표 | 8 |

     `/휴가사용`(ID 1)에는 **"대화상자 열기(Opens a dialog)" 옵션을 체크**한다.
     그러면 /휴가사용 입력 시 날짜 선택기·종류 드롭다운이 있는 등록 양식이 열린다.
     (체크하지 않아도 인자 없이 보내면 양식이 열리도록 처리되어 있다)
   - 공개 범위: 조직(도메인) 내 사용자
4. 구글챗에서 스페이스(톡방)에 휴가봇을 추가한다.

> 슬래시 명령을 등록하지 않아도 `휴가사용 7/28 10:30-15:30`처럼 텍스트로 입력하면 동작합니다.

### 3. 매일 아침 자동 공지 (선택)

1. 공지를 받을 스페이스에서 **앱 및 통합 → 웹훅 관리 → 웹훅 추가**로 Webhook URL을 만든다.
2. `설정` 시트의 `웹훅URL`에 붙여넣고, `공지시간`(기본 8시)을 원하는 시각으로 수정한다.
3. Apps Script 편집기에서 **`installDailyTrigger` 함수를 한 번 실행**한다.

이후 매일 아침(주말·공휴일 제외) 근무 현황 그래프와 휴가자 목록이 자동으로 올라갑니다.

## 시트 구성

`setupSheets()`가 만들어 주는 시트들:

- **설정** — 근무시간, 점심시간(휴가 계산에서 제외 여부), 하루 기본 근무시간, 호칭, 공지 시각, 웹훅 URL
- **휴가종류** — `종류 | 부여(시간) | 공개여부 | 지급주기 | 이월`
  - 부여(시간): 지급주기 한 구간당 부여량. `0` = 잔여 관리 안 함(병가·공가 등)
  - 공개여부 `비공개` = 본인에게만 보이고 종류명 숨김 (기본: 보건휴가)
  - 지급주기: `연간` / `반기`(상·하반기 각각, 예: 반기휴가 24h씩) / `월간`(매달, 예: 보건휴가 8h) / `생일월`(생일 있는 달에만 사용 가능)
  - 이월: `이월`이라고 쓰면 남은 시간이 다음 해로 넘어감 (연간만 해당). 누적 시작 연도는 설정 시트의 `기준연도`
- **명단** — `이름 | 이메일 | 생일 | …`. 이메일은 **구글챗 로그인 계정**과 같아야 본인 매칭이 된다.
  생일(예: `7/28`)은 생일휴가 사용 가능 달 판정에 쓰인다.
  휴가종류명과 같은 헤더의 열(예: `일반휴가(시간)`)에 숫자를 넣으면 그 사람만 부여 시간이 재정의된다.
- **시간표** — `이름 | 월 | 화 | … ` 셀에 `10:00-19:00` 형식. 빈칸 = 그 요일 휴무.
  토·일 근무자가 있으면 `토`, `일` 열을 추가하면 된다. 시간표에 없는 사람은 설정 시트의 기본 근무시간(월~금)이 적용된다.
- **휴가기록** — 봇이 자동 기록 (`상태` 열이 `등록`/`취소`). 수동으로 행을 추가해 과거 데이터를 옮겨올 수도 있다.
- **공휴일** — `날짜(yyyy-mm-dd) | 명칭`. 2026년 공휴일이 미리 입력되며 매년 갱신 필요.

기존 시트에서 옮겨올 때는 `휴가기록` 형식(`등록일시 | 이름 | 이메일 | 종류 | 날짜 | 시작 | 종료 | 사용(분) | 상태 | 비고`)에 맞춰 붙여넣으면 잔여 계산에 그대로 반영됩니다.

## 개발

핵심 로직(파서·휴가 계산·그래프)은 GAS 의존성이 없는 순수 함수라 Node.js로 테스트합니다:

```bash
node test/run.js
```

```
src/
  Util.js             시간·날짜 유틸 (순수)
  Parser.js           한국어 명령 파서 (순수)
  VacationService.js  등록·취소·조회·현황 로직 (순수)
  Chart.js            텍스트 막대그래프 (순수)
  Messages.js         메시지 템플릿 (순수)
  SheetRepo.js        구글 시트 읽기/쓰기 (GAS)
  ChatApp.js          Google Chat 이벤트 처리 (GAS)
  Triggers.js         매일 아침 공지 (GAS)
  Setup.js            최초 시트 생성 (GAS)
```
